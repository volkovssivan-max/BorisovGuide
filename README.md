markdown# 🗺️ Борисов: Путеводитель по городу / Borisov City Guide (v0.1-beta)

Добро пожаловать в репозиторий проекта **Борисов: Путеводитель**! Это сайт, призванное помочь жителям и гостям города Борисова легко находить интересные места, узнавать историю города и места поесть.

> **⚠️ Статус версии:** На данный момент проект находится на стадии **0.1 бета**. Возможны ошибки, интерфейс и функционал будут активно дорабатываться.

---

## 🚀 Функционал версии 0.1-beta

На текущем этапе реализован базовый каркас приложения:
* **Главная страница** — Главная информация о сайте.
* **Основаня информация** — История Борисова кратко.
* * **Общественные места** — удобный сборник всех заведений города(возможны неточности).
* **Адаптивный дизайн** — удобный интерфейс как для ПК, так и для мобильных телефонов.

---

## 🛠️ Технологический стек

Проект построен с использованием следующих технологий:
* **Frontend:** HTML5, CSS3 (Flexbox/Grid)
